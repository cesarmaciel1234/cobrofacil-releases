# Pro Image Converter\n\nHerramienta web para convertir imágenes a PNG con fondo transparente y aplicar efectos 3D avanzados y personalizables.\n\n## Descripción\n\nEste proyecto proporciona una interfaz web amigable para procesar imágenes. Permite a los usuarios cargar imágenes (JPG, PNG, WEBP), eliminar el fondo automáticamente y aplicar una variedad de efectos avanzados como nitidez inteligente, mejora de color, reducción de ruido, suavizado de bordes, sombras realistas, iluminación (highlight), efectos de profundidad, luz de borde (rim light) y viñetas. El objetivo es generar imágenes de alta calidad, adecuadas para uso en cartelería digital, sitios web, impresión o redes sociales.\n\n## Características\n\n-   **Conversión a PNG Transparente:** Eliminación automática de fondos negros y blancos con umbrales configurables.\n-   **Efectos 3D Avanzados:** Incluye sombra, highlight, profundidad, rim light y viñeta, todos con parámetros ajustables para un control fino.\n-   **Mejoras de Imagen:** Nitidez inteligente, ajuste de contraste, saturación, brillo, reducción de ruido y suavizado de bordes.\n-   **Redimensionamiento Inteligente:** Mantiene el aspecto original y centra la imagen en un lienzo de tamaño definido, o permite usar el tamaño original.\n-   **Modo Individual y por Lotes:** Procesa una sola imagen o múltiples imágenes a la vez.\n-   **Preajustes (Presets):** Configuración rápida de parámetros para usos comunes (Cartelería, Web Optimized, Print Quality, Social Media).\n-   **Interfaz de Usuario Intuitiva:** Arrastrar y soltar archivos, controles deslizantes para ajustes en tiempo real, previsualización y descarga.\n-   **Estructura Modular:** Lógica de procesamiento de imágenes separada de la aplicación web Flask.\n\n## Estructura del Proyecto\n\n```\n. (raíz del proyecto)\n├── creator png/\n│   ├── app.py                     # Aplicación Flask (backend web)\n│   ├── convertir_imagen.py        # Script principal de procesamiento de imágenes\n│   ├── requirements.txt           # Dependencias de Python\n│   ├── templates/\n│   │   └── index.html             # Interfaz de usuario (frontend)\n│   ├── uploads/                   # Carpeta para imágenes subidas (temporales)\n│   └── converted/                 # Carpeta para imágenes convertidas (temporales)\n├── Catalogos/                     # Directorio de salida para imágenes de cartelería\n│   └── png_productos/             # Imágenes finales para cartelería\n└── README.md                      # Este archivo\n```\n\n## Requisitos\n\n-   Python 3.x\n-   pip (gestor de paquetes de Python)\n-   Módulos de Python listados en `requirements.txt`\n\n## Instalación\n\nSigue estos pasos para configurar y ejecutar la aplicación:\n\n1.  **Clonar el repositorio** (si aplica) o navegar a la raíz del proyecto.\n\n2.  **Crear un entorno virtual** (recomendado):\n    ```bash\n    python -m venv venv\n    ```\n\n3.  **Activar el entorno virtual**:\n    -   En Windows:\n        ```bash\n        .\\venv\\Scripts\\activate\n        ```\n    -   En macOS/Linux:\n        ```bash\n        source venv/bin/activate\n        ```\n\n4.  **Instalar las dependencias de Python**:\n    ```bash\n    pip install -r \"creator png/requirements.txt\"\n    ```\n\n## Ejecución de la Aplicación\n\nPara iniciar la aplicación Flask:\n\n1.  Asegúrate de que el entorno virtual esté activado.\n2.  Navega al directorio `creator png`:\n    ```bash\n    cd \"creator png\"\n    ```\n3.  Ejecuta la aplicación:\n    ```bash\n    python app.py\n    ```\n\n4.  Abre tu navegador web y visita `http://127.0.0.1:5000/`.\n\n## Uso de la Interfaz Web\n\nLa interfaz de usuario está diseñada para ser intuitiva. Aquí hay una guía rápida:\n\n-   **Carga de Imágenes:** Arrastra y suelta imágenes directamente en la zona de carga o haz clic para seleccionar archivos.\n-   **Modo por Lotes:** Usa el botón \"Modo por Lotes\" para procesar varias imágenes a la vez.\n-   **Presets:** Selecciona un preajuste para aplicar un conjunto de configuraciones optimizadas para diferentes usos (Cartelería, Web, Impresión, Redes Sociales).\n-   **Controles Deslizantes y Checkboxes:** Ajusta manualmente cada parámetro para afinar los efectos de eliminación de fondo, nitidez, color, brillo, sombra, iluminación, profundidad, rim light y viñeta.\n-   **Habilitar/Deshabilitar Efectos:** Usa las casillas para activar o desactivar efectos específicos.\n-   **Carpeta de Salida:** Elige si las imágenes convertidas se guardan en la carpeta temporal `converted/` o directamente en la carpeta `Catalogos/png_productos`.\n-   **Conversión:** Haz clic en el botón \"Convertir Imagen\" (o \"Convertir X Imágenes\" en modo por lotes) para iniciar el procesamiento.\n-   **Previsualización y Descarga:** Para conversiones individuales, se mostrará una previsualización. En ambos modos, podrás descargar las imágenes resultantes.\n\n## Solución de Problemas Comunes\n\n-   **`ModuleNotFoundError` o `ImportError`:** Asegúrate de haber instalado todas las dependencias con `pip install -r \"creator png/requirements.txt\"` y de que tu entorno virtual esté activado.\n-   **\"`C:\Python314\python.exe: can't open file 'convertir_imagen.py': [Errno 2] No such file or directory`\"**: Esto indica que el script `convertir_imagen.py` no se encuentra. Asegúrate de ejecutar `app.py` desde el directorio `creator png`.\n-   **Errores durante la conversión de imágenes:** Revisa la consola donde se ejecuta `app.py` para ver mensajes de error detallados del script `convertir_imagen.py`. A veces, los parámetros extremos pueden causar problemas o las imágenes de entrada tienen formatos inusuales.\n-   **Imágenes \"manchadas\" o de baja calidad:**\n    -   Asegúrate de usar imágenes de entrada con suficiente resolución.\n    -   Incrementa el `output_size` (tamaño de salida) en la interfaz para generar imágenes más grandes.\n    -   Ajusta los parámetros de `sharpnessFactor`, `contrastFactor`, `saturationFactor`, `brightnessFactor`, `denoiseStrength` y `edgePreserveSmoothRadius`.\n    -   Experimenta con `unsharpMaskRadius`, `unsharpMaskPercent` y `unsharpMaskThreshold` para el enfoque final.\n-   **\"Efecto circular\" o artefactos inesperados:** Ajusta los parámetros de los efectos de `depth` (profundidad) y `vignette` (viñeta), especialmente `depthAlphaStart`, `depthOutlineWidth`, `vignetteAlphaStart` y `vignetteOutlineWidth` para controlar su intensidad.\n\nSi encuentras un error que no puedes resolver, por favor, proporciona los detalles del error (incluyendo la salida completa de la consola) y la imagen que estabas intentando procesar.
