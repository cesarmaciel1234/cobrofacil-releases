# Tarjetas ranking

Qué hace: HTML de una tarjeta #1–#4 (nombre, etiqueta, recuadro PNG). Sin precio.

Qué función: `htmlTarjetaRanking` en `tarjeta_ranking.js`.

Cómo funciona: llama `htmlDealStage` de `foto_tarjeta`. La letra tapa hasta que el PNG está listo. PNG chico (`is-chica`) se agranda; sombra 3D en `claridad_50.css`.

Qué no debe cambiar: no agregar precio acá.
