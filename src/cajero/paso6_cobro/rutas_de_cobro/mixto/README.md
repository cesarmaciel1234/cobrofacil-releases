# Proceso mixto

Qué hace: Aísla el reparto en dos medios.

Qué función: `entrar` / `salir` en `proceso.py`. La hoja está en `mixto_en_cobro/`.

Cómo funciona: `salir` oculta el panel y limpia `_mixto_pasos`. No deja una espera de cuenta abierta.

Qué no debe cambiar: el mixto sigue admitiendo dos medios.
