# Proceso mixto

Qué hace: Aísla el reparto en dos medios.

Qué función: `entrar` / `salir` en `proceso.py`. La hoja está en `mixto_en_cobro/`.

Cómo funciona: `salir` vacía los casilleros, oculta el panel y limpia `_mixto_pasos`. Esc llama esto. No deja una espera de cuenta ni importes. `mostrar` también vacía: volver a Mixto no reutiliza el reparto.

Qué no debe cambiar: el mixto sigue admitiendo dos medios.
