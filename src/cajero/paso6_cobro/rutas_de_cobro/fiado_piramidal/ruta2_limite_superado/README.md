# Ruta 2: límite superado

Qué hace: Bloquea el crédito si el carrito supera el disponible.

Qué función: `PanelLimiteSuperado`. PIN de supervisor (`quien_autoriza`). Esc vuelve a los medios.

Cómo funciona: Cuatro dígitos conceden excepción en el cerebro. La deuda se cobra en F6, no acá.

Qué no debe cambiar: el PIN de excepción es de crédito, no de cobranza.
