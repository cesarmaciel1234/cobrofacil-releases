# Proceso transferencia

Qué hace: Aísla la escucha de transferencia.

Qué función: `entrar` / `salir` en `proceso.py`. Alias en `transferencia_en_cobro/`.

Cómo funciona: `salir` esconde alias y el cartel de escucha. Los timers los para `salir_a_metodos`.

Qué no debe cambiar: no abrir `EscuchaMP` al salir.
