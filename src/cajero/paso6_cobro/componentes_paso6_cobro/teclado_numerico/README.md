# Teclado numérico

Teclas del cobro. Emite `key_clicked`. No valida el monto.

Debajo de Salir y Enter, F10 dice «imprime ticket» y, abajo, «fiscal». `mostrar_fiscal` lo deja azul si AFIP está activo y gris si está apagado. El botón no se esconde. Debajo, si el TPV está activo, un rótulo dice «Presione F9» y «Emergencia». No recibe el clic: solo la tecla F9 registra a mano. Si el TPV está apagado, el rótulo no se ve.
