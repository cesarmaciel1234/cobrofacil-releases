# Ingreso de efectivo

El gris de atrás tapa el paso 5. La ventana queda clara, con tres tarjetas. El clic entra a Cambio, Fiado u Otros. Esc vuelve a las tarjetas. No muestra el título «INGRESO DE DINERO». Fiado, al confirmar el importe, sigue en esta ventana: el clic del medio pide el PIN y el QR se dibuja en `fiado/cobro/`.

La punta de esta rama es `punta del piramide.md`.
