# Submotor: Condiciones de Venta

## ¿Qué hace?
Genera los textos legales, garantías y políticas de devolución para una venta normal.

## ¿Qué función cumple?
Asegura que el ticket de venta contenga las políticas actualizadas de la tienda para el cliente regular.

## ¿Cómo funciona?
Implementa `generar_texto(subcontexto, **kwargs)`. Basado en el subcontexto, devuelve el mensaje de venta requerido.
