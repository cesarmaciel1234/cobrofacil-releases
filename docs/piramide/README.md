# Documentación de la pirámide

Las IA que trabajen en este proyecto tienen que leer esta documentación antes de modificar código.

1. Leer este README entero.
2. En la carpeta que se va a tocar, leer su `README.md`. Es la nota de mantenimiento.
3. Subir hasta la primera carpeta de la rama y leer `punta del piramide.md`. Esa nota no está en la base ni en las carpetas de adentro.
4. No cambiar lo que esas notas dicen que no se toca.
5. Si se crea una carpeta, dejar su `README.md`. Si esa carpeta inicia una rama, dejar también `punta del piramide.md`.

## Dónde está cada cosa

- `README.md`: en cada carpeta. Mantenimiento.
- `punta del piramide.md`: solo en la primera carpeta de la rama.
